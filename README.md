# Python Lab

Monorepo para Laboratório de testes, estudos, workshops e etc.
Coleção de mini projetos e exercícios desenvolvidos em Python.

## Projetos

- [Análise de cancelamentos](./analisys-base/README.md) — notebook de análise exploratória que investiga dados de clientes e fatores associados a cancelamentos.
- [Automação de cadastro de produtos](./automation-base/README.md) — automação de interface que lê produtos de um CSV e preenche um formulário no navegador.
- [Chatbot com IA](./chat-bot/README.md) — chatbot desenvolvido com Streamlit e integrado a um modelo Gemini.
- [Sistema de vendas](./dev-base/README.md) — aplicativo Streamlit para cadastrar vendas, consultar registros e visualizar um dashboard.
